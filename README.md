<h1 align="center"> Password Manager🔒</h1>
<h3>Here i have created a password manager were user can store Site name or userame with its password using python</h3>
<h2>✅Key Features</h2>
<ul>
  <li>Data will be permantely store in another password.txt file .</li>
  <li>Data will be secure because the stored password will be encrypted using library like Cryptography:Fernet .</li>
  <li>This library provide a key which will be store in Key.key files, this key is important to run the process of encryption and decryption .</li>
</ul>
